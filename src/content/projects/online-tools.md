## 已上线的工具

- **JSON 格式化**：粘贴即格式化，支持折叠、压缩与转义
- **时间戳转换**：Unix 时间戳与日期互转，含毫秒与常用时区
- **颜色工具**：HEX / RGB / HSL 互转，自动生成配色梯度与对比度提示
- **二维码生成**：纯前端绘制，可调尺寸与容错级别

## 三条设计原则

1. **纯前端**：所有计算都在浏览器里完成，输入的内容不会上传到任何服务器
2. **零依赖**：能用原生 API 解决的就不装库，单个页面通常只有几 KB 脚本
3. **键盘可用**：Tab 能走完全流程，Esc 能关掉弹窗，复制按钮有明确的状态反馈

## 一个小例子

把最常用的时间戳转换抽成了独立函数，页面加载后直接绑到输入框上：

```js
export function toDateText(ts) {
  const d = new Date(Number(ts) * 1000);
  const p = (n) => String(n).padStart(2, '0');
  // 一律按 UTC 取值，避免用户所在时区把日期带偏
  return `${d.getUTCFullYear()}-${p(d.getUTCMonth() + 1)}-${p(d.getUTCDate())}`;
}
```

## 为什么不做成后台服务

一开始也想过写个后端统一处理，但仔细想想这些工具根本不需要服务器：格式化 JSON、换算时间戳、生成二维码，浏览器本身就能算完。省掉服务端之后，页面变成纯静态文件，加载快、没有接口超时，也不用担心用户粘贴进来的内容会留在别人的磁盘上。

代价是没法做特别重的计算，不过到目前为止还没遇到非得上服务端的场景；真遇到了，再单独给那个工具开一个小接口也不迟。
